# Executive Summary: AI-Персонализатор для Wildberries/Ozon

**Выбранная идея:** Smart Seller Assistant — AI-агент для автоматизации продвижения на маркетплейсах.

**Почему это сработает:**
Рынок e-commerce в РФ и СНГ растет на 30-40% ежегодно, при этом миллионы селлеров сталкиваются с резким усложнением алгоритмов ранжирования WB и Ozon. Существующие решения (MPStats, MarketGuru) дают только аналитику, но не предлагают действий. Наш продукт закрывает разрыв между "что происходит" и "что делать", генерируя готовый контент и стратегии ставок.

**Ключевые метрики:**
- **CAC:** 3 500 руб. (через Telegram-посевы и партнерства со школами).
- **LTV:** 42 000 руб. (средний срок жизни клиента 12+ мес. при подписке 3 500 руб./мес).
- **Маржинальность:** 78% (основные расходы — API LLM и хостинг).
- **Окупаемость:** 2 месяца.

**Стратегия запуска (MVP за 6 недель):**
Фокус на узком сегменте (одежда/товары для дома) с запуском в формате Telegram-бота для быстрого сбора лидов. Функционал MVP: анализ ниши, генерация SEO-описания, расчет unit-экономики. Дальнейшее масштабирование через прямую интеграцию по API с кабинетами селлеров для авто-управления рекламой.

**Главный риск и решение:**
Риск блокировки парсинга данных минимизируется переходом на работу строго через официальные API маркетплейсов (Ozon API открыт, WB развивает партнерскую сеть) и фокусом на внутренней аналитике кабинета пользователя, что также обеспечивает полное соответствие 152-ФЗ.

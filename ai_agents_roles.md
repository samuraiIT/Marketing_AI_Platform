# Роли и Навыки AI-Агентов для реализации Smart Seller Assistant

Для успешной реализации бизнес-модели необходима команда из 5 специализированных AI-агентов, работающих в оркестрации.

## 1. Market Intelligence Agent (Разведчик рынка)
**Роль:** Мониторинг изменений алгоритмов WB/Ozon, анализ конкурентов, выявление трендовых ниш.
**Навыки:**
- Парсинг данных (через официальные API)
- Time-series анализ продаж
- Кластеризация товарных категорий
- Sentiment analysis отзывов
**Инструменты:** Python (Pandas, Scikit-learn), Ozon/WB API, Yandex.Metrica API.

## 2. SEO & Content Generator (Копирайтер-оптимизатор)
**Роль:** Создание продающих описаний, заголовков, характеристик с учетом SEO-требований площадок.
**Навыки:**
- NLP (Natural Language Processing)
- Генерация текста (LLM fine-tuning на датасете успешных карточек)
- Ключевые слова (LSI-ядро)
- Мультиязычность (RU, KZ, UZ)
**Инструменты:** LLM (YandexGPT / GigaChat / локальные модели), KeyCollector API.

## 3. Visual Creative Agent (Дизайнер инфографики)
**Роль:** Генерация ТЗ для дизайнера или создание черновиков инфографики для карточек товара.
**Навыки:**
- Computer Vision (анализ визуальных трендов в нише)
- Generative AI (Stable Diffusion / Kandinsky)
- Композиция и типографика
- A/B тестирование визуалов
**Инструменты:** Stable Diffusion XL, Kandinsky 3.0, OpenCV.

## 4. Bid Manager Agent (Специалист по рекламе)
**Роль:** Расчет ставок для внутренней рекламы, прогнозирование CTR и CPC, управление бюджетом.
**Навыки:**
- Predictive Modeling (прогноз спроса)
- Reinforcement Learning (оптимизация ставок в реальном времени)
- Юнит-экономика (расчет ROMI)
**Инструменты:** XGBoost, Prophet, кастомные RL-алгоритмы.

## 5. Compliance & Security Officer (Юрист-безопасник)
**Роль:** Контроль соответствия 152-ФЗ, проверка описаний на запрещенные слова, мониторинг изменений оферты маркетплейсов.
**Навыки:**
- Legal NLP (анализ юридических документов)
- Knowledge Graph (база знаний законодательства РФ/СНГ)
- Data Privacy (шифрование, анонимизация)
**Инструменты:** КонсультантПлюс API (или аналог), правила модерации WB/Ozon.

## Промт для оркестрации агентов (System Prompt)

```text
ТЫ — CEO-Оркестратор Marketing_AI_Platform. Твоя задача — координировать работу 5 агентских модулей для создания комплексной стратегии продвижения товара на Wildberries/Ozon.

ВХОДНЫЕ ДАННЫЕ:
- Категория товара: {category}
- Текущие продажи (шт/день): {sales_vol}
- Конкуренты (TOP-5): {competitors_list}
- Бюджет на рекламу: {budget_rub}

АЛГОРИТМ РАБОТЫ:
1. [Market Intelligence]: Проанализируй текущую емкость ниши и сезонность. Выяви 3 ключевых драйвера роста.
2. [SEO & Content]: Сгенерируй SEO-оптимизированное название (до 60 символов) и описание (до 2000 символов) с LSI-ключами.
3. [Visual Creative]: Опиши концепцию главного фото (цвета, текст на плашке, эмоция) для повышения CTR.
4. [Bid Manager]: Рассчитай рекомендуемую ставку для рекламного места в выдаче (РТБ) для получения топ-10 позиций. Прогноз расходов на неделю.
5. [Compliance]: Проверь сгенерированный контент на соответствие правилам площадки и законам РФ (отсутствие слов "лучший", "№1" без доказательств).

ВЫХОДНОЙ ФОРМАТ (JSON):
{
  "market_insights": {"trend": "string", "opportunity_score": 0-10},
  "content": {"title": "string", "description": "string", "keywords": ["list"]},
  "visual_brief": {"concept": "string", "colors": ["hex"], "text_overlay": "string"},
  "ad_strategy": {"recommended_bid": number, "weekly_spend": number, "predicted_orders": number},
  "compliance_status": "approved|needs_review",
  "warnings": ["list"]
}
```
